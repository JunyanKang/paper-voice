<h1 align="center">让论文，读给你听。</h1>

<p align="center">在 Zotero 中听论文、看原文，也听懂另一种语言。</p>
<p align="center">免费使用 · 离线朗读 · 英语、中文、日语、法语</p>
<p align="center"><a href="#下载">下载</a> · <a href="#快速开始">快速开始</a> · <a href="docs/GUIDE.md">使用指南</a></p>

- **按你的节奏听。** 精听一句、反复听一段，或从当前位置连续听到文末。
- **目光跟得上声音。** 原文随读高亮，页面自动滚动、换栏和翻页；译文就在原句附近。
- **专注论文正文。** 略过可识别的引文标记、图注和出版信息，让听读更连贯，不修改 PDF 或批注。

## 下载

适用于 **Zotero 10**。首次使用请选择完整包，内含插件、离线声音和安装助手。在发布页的 **Assets** 中按系统选择 ZIP。

**Windows · Intel / AMD 64 位电脑**

[获取 Windows 完整包 →](https://github.com/JunyanKang/paper-voice/releases/latest)

**Mac · Apple 芯片（M 系列），macOS 14 或更新版本**

[获取 Mac 完整包 →](https://github.com/JunyanKang/paper-voice/releases/latest)

已有用户：[下载插件 `.xpi`](https://github.com/JunyanKang/paper-voice/releases/latest) · [更新说明](#更新说明) · [其他平台与兼容性](docs/COMPATIBILITY.md)

## 快速开始

1. **安装声音。** 完整解压下载包，打开安装助手，点击「安装声音」，等待「声音已就绪」。
2. **添加插件。** 在 Zotero 的「工具 → 插件 → 齿轮 → 从文件安装插件」中，选择包内的 `.xpi`。
3. **开始听读。** 打开可以选中文字的 PDF，拖选正文，松开鼠标即可朗读。点击右下角的书页精灵，选择模式或打开设置。
