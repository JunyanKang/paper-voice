# 找到适合你的听读方式

[← 返回产品首页](../README.md)

## 四种模式

| 模式 | 如何使用 |
|---|---|
| 划选即读 | 拖选文字，松开后开始朗读；新选区替换上一段。 |
| 全文连读 | 选择起点，点击开始。可从第 1 页、当前页、上次进度或选定位置开始。 |
| 段落循环 | 划选一段文字，重复 2、3、5 次，或持续循环。 |
| 单句精听 | 划选一段文字，逐句重复；用左右按钮切换句子。 |

### 从任意一句开始连读

将全文连读的起点设为 **从选定位置（句首）**。划选任意字母、单词或句子，再点击「从此句开始连读」。插件从选区起始位置所在句的句首开始，接着读到文末。句子跨栏或跨页时，会回到完整句的开头。

选区保留在当前 PDF 会话中。关闭文档后需要重新划选。

### 继续最近一次的进度

「从上次进度」采用这篇 PDF 最近一次实际播放的位置，包括划选、段落、单句和全文模式。重新开始时会从该句句首重读。

全文连读期间，普通点击、滚动或另选文字不会打断播放。主动暂停、停止、切换阅读模式或关闭文档才会改变播放状态。

## 声音与控制

点击悬浮精灵打开面板；右上角设置中可选声音、0.60–1.60× 语速和自动朗读。先点击「试听声音」，找到喜欢的音色。

- 播放键：开始、暂停或继续。
- 方形按钮：停止。
- 模式图标：依次切换四种模式。
- 译文图标：随时打开或关闭译文。

| 快捷键 | 动作 |
|---|---|
| `Option/Alt + P` | 暂停 / 继续 |
| `Option/Alt + T` | 显示 / 隐藏译文 |
| `Esc` | 停止 |

悬浮精灵可拖动。收起面板后仍可使用紧凑播放控制；朗读时精灵会有轻微动态，暂停时静止。

## 随行译文

在设置中开启 **多语言跟读译文**，选择服务及目标语言。这个选项显示当前英文句子的译文，不会额外朗读译文。

默认使用腾讯；也可选择微软或 Google。目标语言包括简体中文、繁体中文、日语、韩语、法语、德语、西班牙语和俄语。繁体中文请使用微软或 Google。

译文显示在当前原句附近。跨栏、跨页时随朗读片段移动，各片段仍显示完整句的译文。滚动期间短暂淡出，停稳后恢复。译文可能覆盖后续未读文字；它不会生成永久批注，也不会改写 PDF。

## 高亮与引文

当前句子以柔和背景色显示；跨栏或跨页时只高亮当前片段。暂停保留高亮，停止或完成后清除。

朗读会略过常见数字引文、作者年份引文、可识别的上标，以及带编号的图表引用。`and/or`、`i.e.`、`e.g.` 会转换为适合听读的英文表达。

具体适用范围见 [兼容性与使用说明](COMPATIBILITY.md)。
