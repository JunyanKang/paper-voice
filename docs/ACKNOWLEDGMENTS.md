# 致谢 · Acknowledgments

Paper Voice 建立在以下开源项目之上，感谢作者和维护者的工作。

Paper Voice builds on the following open-source projects. We thank their authors and maintainers.

| 项目 / Project | 用途 / Contribution |
|---|---|
| [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) | 离线语音模型 / Offline speech model |
| [Kokoro ONNX](https://github.com/thewh1teagle/kokoro-onnx) | 本地语音推理 / Local speech inference |
| [Misaki](https://github.com/hexgrad/misaki) | 中日文发音处理及随包词典 / Chinese and Japanese pronunciation and bundled dictionaries |
| [TinyLD](https://github.com/komodojp/tinyld) | 语言识别 / Language detection |
| [Lucide](https://lucide.dev) | 界面图标 / Interface icons |
| [Translate for Zotero](https://github.com/windingwind/zotero-pdf-translate) | 翻译适配参考 / Reference for translation integration |

第三方组件遵循各自的许可证。完整安装包中的许可证与声明随组件保留。

Third-party components retain their own licenses and notices, included with the components in the complete installation packages.
